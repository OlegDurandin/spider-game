# Версия 1.3 — Три пика

Обновлено 16.11.2026 на https://spider.85-137-95-37.sslip.io/.

Добавлен третий режим: 28 карт на столе, один открытый сброс и 23 карты запаса,
соседние ранги K ↔ A ↔ 2, один проход запаса. Общая таблица перекрытий используется
движком и координатами стола. Поддерживаются подсказка, отмена результата,
текущая и лучшая цепочки, собственный слот `tripeaks_regular`, повтор и вызов
`t1_1_<seed>`. Прежние ссылки и сохранения Паука и Косынки сохранены.

## Выполненные проверки

- `cargo test --workspace --offline`: 49 тестов движка, 5 API, 10 клиента — все прошли.
- Проверены исходные 52 уникальные карты, распределение 28 + 1 + 23 и 10 открытых;
  соседние ранги, закрытые карты, атомарность неверного действия, смена сброса;
  общий стык D[3] → C[2]/C[3] и точная отмена; последняя карта запаса,
  победа/тупик и восстановление цепочек; сохранения и коды трёх режимов.
- `cargo fmt --all --check`: прошёл.
- `node scripts/platform-test.mjs` и `node scripts/sharing-test.mjs`: прошли.
  Это проверки с имитацией SDK, без фактической отправки другу.
- `trunk build --release --locked`: release WASM собран.
- На VPS Docker-сборка выполнила 5 API-тестов и release-сборку API.
- После выкладки оба контейнера healthy, HTTPS `/healthz` возвращает `ok`.
  HTML, JS, CSS, конфигурация и WASM по публичному HTTPS побайтно совпадают
  с локальной сборкой. MIME WASM — `application/wasm`.
- Запросы без авторизации к API Паука, Косынки и Трёх пиков возвращают 401.
