# Компактное меню 1.1.1

Меню использует один сигнал Dialog: переход заменяет содержимое единственной
панели. В паузе — «Продолжить» и три строки; повтор и отправка находятся в «⋯».
Панель новой игры прижата к нижнему краю, имеет высоту по содержимому, крестик,
однострочный выбор сложности и одно основное действие. Декоративная пика,
описание правил и публичные коды из подписей удалены. На результате оставлены
«Новая игра» и «Вызвать друга»; повтор, отмена победного хода, день и партии доступны
через «⋯». Старые нерепродуцируемые партии сохраняют объяснение недоступности ссылки.

Состояние мастей для новой игры не меняет текущий Game. При открытии панели
перечитывается **regular**, независимо от активного дня или вызова. Перед стартом
слот проверяется повторно. Если прогресс появился уже после открытия панели,
предупреждение сначала показывается; старт принимается следующим нажатием.
Если предупреждение уже показано, одного нажатия достаточно. Завершённая,
нулевая и отсутствующая обычные партии не требуют предупреждения.
Первая запись новой партии происходит только при нажатии «Начать игру».

Размер панели ограничен контейнером игры, который использует --app-height от
платформы либо 100dvh. Учтены верхний/нижний безопасные отступы. Высота элементов
нажатия не менее 44 px. Для большого текста используются rem и внутренняя
прокрутка. Поле под панелью inert, события панели не проходят к картам.
Ошибки выбора смешанной масти и нарушения рангов теперь имеют разные объяснения.

## Проверки

Выполнены `cargo test --workspace --locked` (46 тестов: 33 engine, 4 server,
9 web), `cargo fmt --all --check`, `docker compose build web api`
(включая Rust-тесты и `trunk build --release --locked`) и
`docker compose --profile tools run --rm --no-deps platform-test`.
Целевые тесты проверяют условия предупреждения, повторную проверку обычного слота
и разные сообщения для масти и ранга. Существующие тесты изоляции слотов,
повтора, истории и решений каталога остаются в полном прогоне.

Настоящий Chrome с WASM из Docker; мобильные размеры заданы iframe в отдельном
локальном origin localhost:8095. Это **браузерная эмуляция**, а не проверка на iPhone
или в настоящем мобильном клиенте Telegram/VK. Оснастка:
`scripts/qa/compact-menu.html`; фикстуры экспортирует
`cargo run --locked -p spider-engine --example verify_catalog -- /tmp/spider-release111-fixtures`.
В оснастке JSON раскладов сохраняется текстом, без потери точности u64 seed через
JavaScript Number. Оснастку и фикстуры нельзя выкладывать на рабочий origin.

| Вызов → пауза → новая игра → 4 масти → крестик | 0 панелей, прежние карты/режим/1 ход/1 undo; все три сохранения побайтово прежние. Последующая отмена хода сработала. |

| Обычный слот отсутствует, без ходов или завершён | Предупреждение не показано. |

Во всех измеренных открытых состояниях в DOM был один role=dialog, у стола inert;
в подписях заголовков и контекста публичных кодов не было. При закрытии панели
стол возвращался без лишнего касания и без изменения сохранений.
