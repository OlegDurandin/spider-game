# Компактные карты

Высота уменьшена со 160 до 128 условных единиц (−20%) при прежней ширине.
На ширине экрана 390 px это примерно 33 × 54 CSS px вместо 33 × 67.
Номинал и масть сохраняют прежний размер. Иллюстрация занимает область с 42
до 122 единиц, вписывается целиком через object-fit:contain, без растягивания.
Высота столбца, пустое место и рамка выбранной стопки приведены к 128 единицам.
Перетаскивание и анимации используют реальные DOM-размеры карт.

Проверено в Chrome на ширине 390 px: полные рисунки, перенос 7–6–5 на 8,
увеличение счётчика до одного хода и точная отмена. В Docker прошли все 30
существующих Rust-тестов и release WASM-сборка. Новые тесты для изменения
геометрии не добавлялись.

Сравнение: cards-proportions-preview.png. Воспроизводимый рендер —
scripts/render-card-proportions.mjs через @resvg/resvg-js в Docker.
