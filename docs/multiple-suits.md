# Режимы на 1, 2 и 4 масти

«Новая игра» → выбрать число мастей → «Начать новую игру». Выбор сам по себе
не заменяет текущую партию; «Вернуться к игре» сохраняет её.

Колода всегда содержит 104 карты: 8 копий каждого ранга в одной масти,
4 копии каждого ранга в каждой из двух мастей (пики/червы), 2 копии каждого
ранга в каждой из четырёх мастей (пики/червы/трефы/бубны).

- На карту на ранг старше можно положить карту или допустимую группу любой масти.
- Переносимая группа должна убывать по рангам и иметь одну масть.
- Снимается только открытая серия K–A одной масти.
- Отмена, подсказка, касания и перетаскивание используют общие правила движка.
- Раздача и победа сохраняют прежние условия.

Формат сохранения v2 добавляет mode в позицию и снимки истории. Старый формат
v1 восстанавливается как одна масть без изменения карт, счётчика ходов и отмен.
Ключ localStorage оставлен прежним. Откат на старую сборку не поддерживает v2.

Проверено в Docker: 19 тестов движка и 5 тестов жестов/подтверждения новой игры,
release WASM-сборка. В Chrome проверены запуск двух/четырёх мастей, красные
индексы, символы всех мастей и меню новой игры на ширине 390 px. Проверка
на физическом телефоне внутри Telegram не выполнялась.
