# Экран «Как играть» — 17.11.2026

Встроенная справка общая для браузера, Telegram и VK. Кнопка `?` рядом с паузой
открывает правила активного пасьянса и его варианта. Ссылка «Как играть?»
в «Новой игре» использует выбранный режим и количество мастей; возвращает
к тому же выбору. Прежний пункт меню действий открывает этот же экран.

Тексты находятся в `web/src/help.rs`: цель, способ хода, статический пример
с теми же SVG-картами и раскрываемые вопросы. У Косынки группа 7♥–6♠
имеет единое выделение. У Трёх пиков показана последовательность 8♣ → 7♥ → 6♦.
Примеры Паука меняются для одной и нескольких мастей.

При открытии справки стол остаётся смонтированным. Игровые команды и сохранение
не вызываются. Возврат внизу, «Назад» вверху, Escape, браузерный Back и событие
платформенного Back закрывают один уровень. У Telegram подключена штатная
BackButton; доступность этой кнопки синхронизируется с открытой панелью.
Дублирующий обработчик Escape больше не закрывает сразу все уровни.

и прокрутки; его генерирует `engine/examples/verify_help.rs`.

Воспроизведение (Python с установленным Playwright и Chrome):

```sh
cargo run --offline -p spider-engine --example verify_help -- /tmp/help-spider.json
(cd web && trunk build --release --locked)
python scripts/qa/help-browser.py /tmp/help-spider.json
```

На физическом телефоне и в настоящих Telegram/VK WebView проверки не проводились.
