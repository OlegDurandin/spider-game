# Card artwork

Vector Playing Cards by Byron Knoll and contributors.
Source: https://github.com/notpeter/Vector-Playing-Cards
Revision: 861b338eb931d635c442b568071e3829e552f383

The original artwork is released into the public domain, with WTFPL as an
alternative where applicable. Images are bundled locally, not hotlinked.
Project README and credits:
https://github.com/notpeter/Vector-Playing-Cards/blob/861b338eb931d635c442b568071e3829e552f383/README.md
https://github.com/notpeter/Vector-Playing-Cards/blob/861b338eb931d635c442b568071e3829e552f383/CONTRIBUTORS.md

The game uses adapted illustration-only files in art-v2/: original corner
indices and outer card borders are removed. The game renders one separate
index strip above the complete illustration. Rebuild with scripts/prepare-card-art.py.

All four suits use the original court portraits. Numeric cards 2–10 show one
large symbol drawn for this project (numeric-S/H/C/D.svg); new red/club/diamond
aces use that same clear symbol. The original ornate ace of spades is preserved.
